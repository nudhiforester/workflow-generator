## Lakukan perbaikan berikut :
1. Setelah login berhasil, sistem akan menampilkan halaman utama.
2. Halaman utama pertama kali menampilkan lembar kosong, jadi tidak perlu langsung menampilkan shape dari project.
3. Di sisi kiri menampilkan list project yang sudah pernah di buat.
4. Form tambah project seharunya tidak selalu muncul, akan muncul jika tombol creat project di click.
5. Begitu juga ketika user click di luar form creat project maka form tersebut menghilang.
6. perbaiki tampilan dropdown profile karena sekarang nampak berantakan.
7. Shape pada lembar kerja seharusnya dibuat agar bisa di geser atau diubah posisinya.
8. Untuk membuat garis, diperlukan titik pada masing-masing sisi shape untuk menentukan dimana yang harus di click pada saat akan membuat garis.
9. animasi seperi aliran cahaya tidak berfungsi, malah berubah jadi garis putus-putus.
10. Ketika membuat atau mengubah shape dan menyimpannya, seharusnya form menghilang setelah berhasil.
11. Rapihkan tampilan dropdown pada tombol download
